# Atlas Translate

Atlas Translate ist eine kleine Windows-Desktop-App zum Übersetzen von JSON- und Textdateien.

## Download

Die aktuelle Version ist über die GitHub Releases verfügbar:

- [Atlas Translate v0.1.1](https://github.com/flathack/AtlasTranslate/releases/tag/v0.1.1)

## Hinweise

- Release-Dateien liegen auf GitHub.
- Der Quellcode wird privat verwaltet.
- JSON-Strukturen bleiben bei der Übersetzung erhalten.
